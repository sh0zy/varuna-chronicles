# 07 やりこみ要素と報酬

**すべての項目について、次の4つを説明できる状態にする。** 説明できない項目は作らない（または統合する）。
- **発見**：何を発見するか ／ **判断**：どんな判断をするか ／ **違い**：他と何が違うか ／ **報酬**：報酬によって何が変わるか
