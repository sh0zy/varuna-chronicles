# 03 ワールド設計

## 1. 規模の考え方

- **地図の面積で広さを測らない。** 評価の指標は「発見の間隔」「景観が変わる間隔」「判断の回数」とする（計測方法は `09`）。
- 目安（仮）：各大地域は歩いて端から端まで 12〜18分。移動中の「気になる物」（痕跡・ランドマーク・生態イベント）の出現間隔は **平均40〜90秒**、同じ種類の発見が3回続かないようにする。
- 地域の境界に壁は作らない。**植生・標高・水系・気温**が徐々に変わる「移行帯」でつなぐ。移行帯には、両方の地域の生物が混ざる固有の生態を置く（例：草海と樹海の境界＝オルガの倒木地帯）。

## 2. 地域の接続

```
                   ⑥白嶺の氷原 ──(氷河下の道：ウルマ後)── ⑦黒曜の火口帯
                  ╱  (雪解けの尾根：常時／寒さ対策)          │
     ⑤天帆の断崖 ╱                                           │(溶岩洞：耐熱装備)
      │(上昇気流の階段：滑空)                                 │
 ②翡翠の樹海 ──(根の地下道：オルガ後)── ④潮鏡の内海 ────(沿岸航路：水門後)──┤
   │  ╲(倒木橋：オルガ後／迂回路：浅瀬の渡し)   │(干潟：干潮時徒歩)          │
 ①暁の草海 ─────────(大河を船で下る)───────────┘                         │
   │                                                                      │
 ③赤層の峡谷 ──(断層の階段：地層読み)── ⑧星骸の盆地 ── 原環の心臓（第5幕）
```

| 接続 | 通常の手段 | 能力がなくても通れる迂回路 |
|---|---|---|
| 草海→樹海 | オルガが倒した巨木の橋（解決後） | 浅瀬の渡し：乾季の夕方だけ水位が下がる。《ソラクビ》の群れが渡る場所をたどれば見つかる |
| 樹海→内海 | 根の地下道（オルガ解決後に渡りの民が案内） | 樹冠を伝う道（登攀が必要。時間がかかる） |
| 草海→峡谷 | 大河沿いの赤い崖道 | 常時通れる |
| 内海→断崖 | 船で断崖の下へ行き、上昇気流で登る | 崖の古い階段（長い。途中に営巣地があり、《トサカバネ》の警戒を解く必要がある） |
| 断崖→氷原 | 雲海を越える滑空路（セイラ解決後） | 雪解けの尾根（寒さ対策の装備が必要） |
| 氷原→火口帯 | 氷河下の道（ウルマ解決後） | 山脈沿いの長い回り道 |
| 峡谷→盆地 | 断層の階段（地層を読んで安全な層を選ぶ） | 第3幕まで最下層は閉じている（物語上の制限。見える場所に明確な理由を置く：崩落した大階段） |

## 3. 移動手段と得意・不得意

| 手段 | 得意 | 制約 | 探索の意味 |
|---|---|---|---|
| **徒歩** | 痕跡を読む、静かに近づく、細部の調査 | 遅い | 最も多くの情報が得られる手段。しゃがむと足音と匂いが減る |
| **登攀** | 岩壁、巨木、遺跡の外壁 | スタミナを消費する。濡れた岩は滑る（見た目で判別できる光沢） | 固定具（工作ツリー）で登攀路を「作る」と、次回以降の近道になる |
| **騎乗** | 平地の長距離移動、追跡、群れへの同行 | 登れない。騎獣ごとに怖がるものがある（《カゼアシ》は肉食獣の匂いに怯える） | 騎獣ごとに役割がある（下表） |
| **滑空** | 高所から低所への移動、上昇気流を使った横断 | 上昇気流がないと降りるだけ。強風では流される | 天帆の断崖で本格化。雲の形と鳥の旋回から上昇気流を読む |
| **船** | 内海の広域移動、潮流に乗る | 浅瀬と干潟に入れない。大型の海生生物に警戒される | 潮位で出現する遺跡を探索する |
| **潜水** | 海草の森、沈没都市、海溝 | 深度と時間の上限がある（装備で拡張） | 光が深さで変わる。暗い海溝では生物発光を頼りに進む |

### 3.1 騎獣と共生生物の役割分担（最強の1体を作らない）

| 生物 | 役割 | 得意 | 苦手 |
|---|---|---|---|
| カゼアシ | 騎乗（高速） | 草原の疾走、跳躍、追跡 | 登れない、臆病、泳げない |
| ツノナガ（小型角竜） | 騎乗（重量）・荷運び | 茂みを押し分ける、荷物を多く運ぶ | 遅い、急旋回が苦手 |
| ソラトカゲ | 索敵 | 高所から周囲を見る、小動物を見つける | 寒さに弱い |
| ハヤイルカ（魚竜） | 潜水支援 | 深く潜るときに空気の泡を運ぶ、海流を先導する | 陸に上がれない |
| トサカバネ | 滑空支援 | 上昇気流の場所を旋回で示す | 雨の日は飛ばない |
| ユキオイ（小型長鼻類） | 雪原の荷運び | 深雪を踏み固めて道を作る、体温で凍えを防ぐ | 暑さに弱い |
| ツチネズミ | 探索補助 | 狭い穴に入って小さな物を持ってくる、地下の空洞に反応する | 戦闘ではまったく役に立たない |

## 4. 8つの大地域

各地域の詳細設計。**色彩・音・天候・地形・ランドマーク・探索方法・文化・食物連鎖・サイドストーリー**を定める。

### ① 暁の草海

| 項目 | 設計 |
|---|---|
| 色彩 | 朝：薄金と青灰の霧。昼：黄緑と空色。夕：琥珀。**基調色：麦わら色 #C9B46A、霧の青 #9FB3BF** |
| 音 | 長い草の擦れる音（風の強さで音程が変わる）。遠くのソラクビの低い鳴き声（地面を伝う超低音を振動で表現）。ヒバリに似た小型翼竜の囀り |
| 天候 | 朝霧（高頻度）、夕立、乾季の野火（遠景の煙） |
| 地形 | 緩やかな丘陵、大河の蛇行、古い群れの道が作った浅い溝、点在する岩の丘 |
| ランドマーク | 渡りの丘、大河の曲がり（拠点）、「九本石」（不自然に並んだ岩＝環刻文明の測量点）、遠景の環状山脈 |
| 探索方法 | **足跡・風向き・群れの行動を読む**。見通しがよいので、遠くの煙・鳥の旋回・群れの向きから行き先を決める |
| 文化 | 渡りの民の移動集落。天幕は巨獣の皮と骨で作られ、群れの移動に合わせて畳まれる |
| 食物連鎖 | 草 → ソラクビ・カゼアシ・ヒメヨロイ → クサガリ（群れ）・カゲワタリ（上空から小動物を狙う） → 死骸 → ホネツツキ・ツチネズミ・糞虫 → 土 |
| サイド | 「帰らない巨獣」「柵の向こうの道」「最後の渡り」（`07`参照） |

### ② 翡翠の樹海

| 項目 | 設計 |
|---|---|
| 色彩 | 深緑と翡翠色、苔の黄緑、光の柱の白金。**基調色：翡翠 #3E7D5A、木漏れ日 #F2E6B0** |
| 音 | 樹冠の遠い鳴き声（上下の定位を強調）、水滴、根のきしみ。《オオヤンマ》の羽音 |
| 天候 | 霧雨、にわか雨の後の蒸気、夜の生物発光 |
| 地形 | **3層構造**：林床（湿地・根の洞窟）、中層（巨木の枝の道）、樹冠（光のある別世界） |
| ランドマーク | 翡翠の門（入口の巨大な根のアーチ）、千年リンボク、「根の水路院」（遺跡） |

| 文化 | 樹上集落「コズエ」。住民は森を倒すオルガを畏れながら、倒木地帯でキノコを採って暮らしている |

| サイド | 「怪物の声の正体」「光の苔の道」「コズエの境界線」 |

### ③ 赤層の峡谷

| 項目 | 設計 |
|---|---|
| 色彩 | 赤・橙・白の縞模様の地層、紫の夕影。**基調色：赤層 #B5553A、灰白層 #D9D4C7** |
| 音 | 風の笛（天然の穴を通る風）、砂の流れ、遠い落石 |

### 終盤領域 原環の心臓

- 内海の底から環状山脈の内部に広がる、アーケアの体内。
- **これまで自然地形だと思っていたものがアーケアの器官とつながっていた**ことを見せる：草海の小川の源流、峡谷の灰白層、内海の海溝、氷原の熱炉は、すべて心臓へ続く管の出口だった。
- 色彩：真珠層の虹色、記憶層の琥珀色の縞。音：巨大な心拍（戦闘のリズムに組み込む）。

## 5. 能力ゲート（再訪の設計）

| 地点（最初に見える場所） | 最初に見えるとき | 進む手段 | 見返り |
|---|---|---|---|
| 大河の滝の裏（草海） | 第1幕、拠点から | 潜水（初級）または振動感知で裏の空洞に気づき、横の岩壁を登る | 環刻文明の測量記録 |
| 千年リンボクの樹冠（樹海） | 第2幕の初め | 固定具で登攀路を作る、またはコズエザルの枝の道をたどる | 樹冠の営巣地と、隠された眺望地点 |
| 沖の遺跡（内海） | 草海の高台から遠くに見える | 船＋干潮 | 沈没都市の外周区 |
| 氷河の下（氷原） | 断崖から見下ろせる | ウルマ解決後の氷河下の道、または熱を運ぶユキオイの同行 | 熱炉の制御室 |
| 峡谷の断層の最下層 | 第2幕 | 第3幕で開く（物語上の制限） | 星骸の盆地 |

**原則**：再訪したとき、必ず「前は気づかなかった何か」が見えるようにする。能力による再訪（物理的に進めるようになる）と、知識による再訪（壁画の意味が分かるようになる）を半々にする。

## 6. ファストトラベル

- 移動手段：各地の「渡りの石」（解放した場所へ移動できる）。読み込みの目標は10秒以内（実測で確認する）。
- **自分で移動する価値**：
  - 移動中にだけ起きる生態イベント（群れの移動、狩り、縄張り争い）がある。イベントは1時間あたり2〜4回を目安に配置し、図鑑の観察項目の多くはこうしたイベントでしか埋まらない。
  - 騎乗で群れに同行すると、群れがプレイヤーを受け入れた状態で目的地に着き、そこでしか見られない行動を観察できる。
  - 夜間の移動は、生物発光と夜行性の生物を見る機会になる。
