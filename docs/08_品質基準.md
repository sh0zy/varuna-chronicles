# 08 グラフィック・音・UI・性能の品質基準

**原則**：グラフィックを最優先の品質基準にする。ただし、静止画だけで判断しない。移動中のちらつき、草木の表示の切り替え、影の安定、アニメーションのつながり、カメラの見やすさまでを確認する。操作感を損なうほど不安定な描画は、完成品質とみなさない。

## 1. グラフィックの基準

### 1.1 画面の目標

「古代の自然を撮影した映画のような美しさ」と「未知の世界に踏み込む幻想性」を両立させる。**画面を常に派手にしない。** 静かな景色（霧の草原、雨の樹海）と壮大な景色（群れの横断、雲海、覚醒するアーケア）に強弱をつける。

### 1.2 項目別の合格基準（製品版）と、垂直スライスでの状態

| 項目 | 製品版の合格基準 | 垂直スライスの状態（2026-09-22） |
|---|---|---|
| 生物の皮膚・鱗・羽毛・毛 | 近距離（2m）で鱗の形と濡れが分かる。羽毛と毛は房の流れが見える | **仮素材**：手続き生成の鱗模様（ボロノイ）と凹凸。羽毛は板状の房。近距離の品質は製品版に届かない |
| 筋肉・脂肪・皮膚の動き | 歩行で肩と腿の筋肉が動き、腹が揺れる | **未実装**：骨の回転のみ（二次運動なし） |
| 体重による地面の沈み | 足跡が沈み、泥は盛り上がり、水面は波打つ | **実装済み（簡易）**：体重に応じた深さの足跡を実際の着地位置に残す。巨大生物は土煙と画面の揺れ。泥の盛り上がりは未実装 |
| 草の揺れ | 風と、生物の脚・体が押しのける | **実装済み**：GPU上の草（風のうねり、生物の脚ごとの押しのけ、最大16か所） |
| 霧を通る光・木漏れ日・雲の影 | 霧の中に光の筋、雲の影が地面を流れる | **実装済み（簡易）**：高さ霧＋太陽方向の散乱、朝霧の層、雲の影、樹海の縁の光の柱。本格的な体積光は未実装 |
| 浅瀬・濁流・深度による光 | 浅瀬で川底が透け、深い所は暗く、流れが見える | **実装済み（大河のみ）**：深さで透明度と色が変わる水面、流れの模様、岸の泡。海と潜水は未実装 |
| 岩の地層・濡れた石・苔・風化 | 地層の縞、上面の苔、雨で濡れる | **実装済み（簡易）**：三面投影の岩の細部、縞、上面の苔、雨の濡れ |
| 遠景〜近景の統一 | 遠景の山まで空気遠近で色がつながる | **実装済み**：高さ霧と空気遠近（アーケアの背殻は霞に溶ける） |
| 夜空・極光・火山光・生物発光 | 場所ごとに使い分ける | **一部**：星・天の川・月光・ホタルゴケムシの光。極光と火山光は該当地域が未制作 |
| 巨大感 | 足音の遅れ、木との比較、影の移動、遠い声、歩行の遅れ | **実装済み**：重さに応じた足音（超低音）、画面の揺れ、巨体ほど旋回・加速が遅い、翼竜の影、遠くまで届く低い声 |

### 1.3 動いている時の確認項目（すべての地域で毎回確認）

| 確認 | 基準 | 垂直スライスでの結果 |
|---|---|---|
| 影のちらつき | 移動中に影の輪郭が泳がない | 影カメラをテクセル単位に揃えて抑制済み。近距離の影は75m（中）まで |
| 草木の表示の切り替え | 切り替えの境目が目立たない | 草は距離で高さを縮めて消す（24〜31m、遠景は70〜88m）。境目は「近くでだけ背の高い草」に見える。**要改善** |
| 生物のアニメーションのつながり | 状態が変わるときに姿勢が飛ばない | すべての姿勢の値を時間でなめらかに補間 |
| カメラ | 地形・幹にめり込まない。巨体の近くでは引く | 地形と幹の当たりで手前に寄せる。巨大生物の近くと注目中は距離を伸ばす（自動テストで確認） |
| 細かい模様のちらつき | 中距離で鱗・地形の模様がちらつかない | 模様を距離で弱めるよう修正した（修正前はちらつきがあった） |

## 2. 音の基準

| 項目 | 基準 | 垂直スライス |
|---|---|---|
| 状況が読める音 | 声・足音・風・水で、見えない物の方向と大きさが分かる | 立体定位の鳴き声（種ごとの声質）、重さで変わる足音、風・草・川・雨・焚き火の環境音、塔の共振音。**方向つきの音の字幕**（例：〔翠角王の咆哮　北〕） |
| 音楽を流し続けない | 自然音だけの時間が長い | 音楽は絶景・発見・ボス戦のときだけ |
| ボス戦のリズム | 生物の足音・呼吸が戦闘の拍になる | オルガの足音で打音が鳴る。予兆は鼻息・共振の高まり・体の震えの音で分かる |
| 素材 | 製品版は実録音＋合成 | **仮素材**：すべて WebAudio の手続き合成 |

## 3. UI の基準

- 通常の探索では、方位（と風向きの線）と追跡中の目的だけを表示する。体力とスタミナは変化したときだけ出る。
- 必要な情報は明確に：調べられる物に近づくと、キーのアイコンと動作を表示する。長押しは円の進み具合で示す。
- 日本語を基準に、字幕・操作説明・用語を統一する（用語は `01` の用語集）。
- 文字サイズ（3段階）、色の識別補助（形と記号で区別）、操作の割り当て変更、カメラの揺れ、長押しと切り替えの選択を設定できる。モーションブラーは使っていないので設定項目も置かない（存在しない機能を項目だけ置かない）。
- フォトモード：焦点距離、ピント距離、ぼけ、時刻のプレビュー（閉じると元に戻る）、露出、彩度、コントラスト、UI非表示、撮影した写真は拠点に飾られ、PNGでも保存できる。

## 4. 性能の基準と実測

### 4.1 目標（製品版）

| 画質 | 目標 | 対象機器（想定） |
|---|---|---|
| 低 | 30fps以上（33.3ms以内）、99%値 50ms以内 | 内蔵GPU（Intel Iris Xe 級） |
| 中 | 60fps（16.7ms）、99%値 25ms以内 | 中位の単体GPU（RTX 3060 級）※未検証 |
| 高 | 60fps | 上位の単体GPU ※未検証 |

### 4.2 垂直スライスの実測

**測定環境**：Intel Core i5-1340P ／ Intel Iris Xe（内蔵）／ 16GB ／ Windows 11 ／ Microsoft Edge（ANGLE D3D11、ヘッドレス）／ 1600×900、描画倍率1.0 ／ **バッテリー駆動（残量20〜30%台、電源プラン「バランス」）**。バッテリー駆動のため性能が抑えられており、同じ条件で繰り返しても数ms ばらつく。**電源接続時の測定はまだ行っていない。**

最適化（静的な小物の結合・影を落とす範囲の制限・樹木の区画分けと近い区画だけの影・地形の間引き）後の最終測定（中画質、`tools/play.mjs`、各場面5秒）：

| 場面 | 平均 | 95% | 99% | CPU（JS全体） | 描画命令 | 三角形 |
|---|---|---|---|---|---|---|
| V1 渡りの丘（夜明け） | 24.7ms（約40fps） | 29.4ms | 33.8ms | 13.4ms | 476 | 212万 |
| V2 野営地の崖 | 23.1ms | 30.9ms | 37.1ms | 18.9ms | 444 | 187万 |
| 野営地の中 | 21.2ms | 30.3ms | 38.0ms | 17.9ms | 491 | 178万 |
| V3 翡翠の縁 | 21.0ms | 27.7ms | 41.7ms | 15.6ms | 257 | 228万 |
| オルガ（戦闘前） | 20.5ms | 27.2ms | 35.5ms | 14.4ms | 238 | 226万 |
| オルガ戦 | 21.8ms | 30.1ms | 41.6ms | 15.1ms | 238 | 226万 |
| 夜の草海 | 19.8ms（約50fps） | 26.6ms | 47.3ms | 14.5ms | 338 | 174万 |

最適化前の同じ場面（全画質の比較。この時点でもバッテリー駆動）：

| 画質 | V1 | 野営地 | 翡翠の縁 | オルガ戦 | 夜の草海 |
|---|---|---|---|---|---|
| 低 | 26.7ms | 21.5ms | 22.0ms | 25.7ms | 18.7ms |
| 中 | 29.3ms | 24.1ms | 25.8ms | 26.1ms | 23.6ms |
| 高 | 32.3ms | 27.4ms | 29.3ms | 29.7ms | 25.3ms |
| 中（1920×1080） | 32.7ms | 28.2ms | 28.5ms | 29.8ms | 26.5ms |

**分かったこと**：
- この機器では、処理の限界は画素の数ではなく**頂点と描画命令の数**だった（解像度を1/4にしても速くならなかった）。
- 描画命令の CPU 負担が大きく、区画を細かく分けすぎると逆に遅くなる（120m区画で1300命令・CPU 20ms）。260m区画と「近くの区画だけが影を落とす」の組み合わせが、この機器では最もよかった。
- 最初に遊び始めた数秒と、新しい物が初めて映る瞬間に、100ms〜900ms の引っかかりが出る（シェーダーの準備と思われる）。**要改善**。
- 最終測定では、中画質でも全場面で平均 33.3ms 以内・99%値 50ms 以内（「低」の目標値）に収まった。ただし最大値では 130ms 前後の引っかかりが残る。**「中」「高」の目標（60fps）は、この機器では満たさない**（想定対象外の機器のため）。
