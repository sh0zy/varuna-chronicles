## 4. 次にやること（優先順）

1. **人によるプレイテスト**（5〜8人）で、`11` の 5.2 の問いに答える。
2. 読み込み直後と、新しい物が初めて映るときの引っかかり（最大900ms）を無くす（シェーダーの事前準備）。
3. 電源接続時と単体GPUで性能を測り直し、画質の目標を決める。
4. 草の表示の境目、V2 の崖からの構図、翠角竜のフリルの形を直す。
5. 実機のゲームパッドで操作を確かめる。
6. オルガの「鎮静」「討伐」の決着を加え、報酬の価値が揃っているかを確かめる。
7. 製品版エンジン（UE5）で、同じ区間の製品版の垂直スライスに着手する。
