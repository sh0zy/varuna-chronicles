# 06 生物一覧

- **主要生物 64種**（環守の種を含む）＋**環境生物 34種**＝**合計 98種**（初期目標：主要60種以上、総数90種以上）。
- 「モチーフ」は実在の古生物（化石から分かる知見の出典となる分類群）。それ以外の生態・能力・色彩はすべて**ヴァルナ独自の創作**。
- **骨格系統**：同じ系統を共有する種は、**シルエット（比率）・行動・生態上の役割のすべてが異なる**ものに限る。色違いを別種として数えない。
