### 1.2 6系統のプレイスタイル

| 系統 | 中心の道具 | 何を狙うか | 強み | 弱み |
|---|---|---|---|---|
| **重撃**（重い武器で姿勢を崩す） | 骨鎚、大斧 | 姿勢値（体勢ゲージ）を削り、転倒させる | 大型生物の転倒で、全員が攻撃できる時間を作る | 振りが遅い。小型の群れに弱い |
| **軽撃**（軽い武器で隙を突く） | 双刃、骨槍 | 攻撃後の硬直、柔らかい部位 | 移動しながら攻撃できる、回避からの反撃が強い | 硬い外皮に弾かれる |
| **射撃**（遠距離から部位と行動を制御） | 投石帯、弓、銛綱 | 眼・関節・装置など特定の部位 | 部位を壊して行動を封じる（例：角を折ると突進が弱まる） | 接近されると弱い、矢や石の数に上限がある |
| **罠**（罠と地形で戦況を作る） | 泥罠、倒木の仕掛け、煙罠、音罠 | 地形そのもの | 準備すれば戦闘の半分を有利に進められる | 準備に時間がかかる、動き回る敵には当てにくい |
| **共闘**（共生生物と連携） | 騎獣、索敵の生物 | 共生生物の特技 | 騎乗突撃、囮、索敵 | 共生生物が怯えると逃げる。生物ごとに苦手がある |
| **調査**（調査と準備で危険を減らす） | 調査手帳、匂い消し、鳴き真似 | 戦闘そのものを避ける、有利な状況で始める | 弱点・習性を知ると、戦闘前に大きな有利を作れる | 直接の攻撃力は低い |

**どの系統でも本編をクリアできる**ように、各ボスに少なくとも2系統の「得意な攻略法」を用意する（`04` の各段階の攻略を参照）。

### 1.3 敵の状態（体力と攻撃力の数値だけで難度を作らない）

| 状態 | 内容 | 画面での見え方 |
|---|---|---|
| 外皮と部位 | 硬い部位（弾かれる、火花）と柔らかい部位（血の代わりに鱗片と体液の飛沫）。部位ごとに耐久値を持ち、壊すと行動が変わる | 攻撃が弾かれたときの音と、手元の振動で分かる |
| 視野 | 種ごとの視野角と距離。肉食獣は正面に狭く、草食獣は横に広い | しゃがんだ草むらの中は見えにくい |
| 聴覚 | 足音、道具の音。しゃがむと小さくなる | 画面端の「音の波紋」（控えめに表示。設定で消せる） |
| 嗅覚 | **風向き**に依存する。風上から近づくと、見えていなくても気づかれる | 画面上部の方位に、風向きを示す細い線 |
| 警戒 | 無警戒 → 気づき → 警戒 → 敵対／逃走。警戒は時間で下がる | 生物の姿勢（首を上げる、耳を立てる、尾を振る） |
| 疲労 | 大型生物は連続で突進すると疲れ、口を開けて息をする（攻撃の好機） | 呼吸の音と、口から出る白い息（寒冷地） |
| 負傷 | 部位が壊れると、その部位をかばう動きになる（脚を引きずる、片翼で飛べない） | 歩き方が変わる |
| 空腹 | 空腹の肉食獣は執拗に追ってくる。満腹なら追わない | 腹の膨らみ（食後）、痩せた脇腹 |

### 1.4 大型生物の戦闘の読みやすさ

- **予兆の3拍**：予兆（0.6〜1.5秒。姿勢・呼吸・音で示す）→ 攻撃 → 硬直（反撃の機会）。
- 当たり判定は見た目に合わせる。角の突きは角、尾の薙ぎは尾の軌跡。**見た目より大きい判定は作らない**。
- カメラ：注目中は、プレイヤーと注目部位の両方を画面に収める。巨体が画面を覆うときは自動で引く。遮蔽物は半透明にする。
- 回避後の状況：回避した直後に、次の攻撃が見える位置にいられるように、回避の方向と距離を設計する（背後への回り込みは有利になる）。

### 1.5 難易度

| 難易度 | 対象 | 変わること |
|---|---|---|
| 物語 | 物語と探索を中心に楽しみたい人 | 受けるダメージ半分、予兆が長い、痕跡の提示が詳しい |
| 旅人（標準） | ― | 基準 |
| 渡り読み | 戦闘を深く攻略したい人 | 予兆が短い、生物がより賢く連携する、回復物資の効果が下がる |
| 環守 | 熟練者（クリア後） | 生物が新しい行動を使う（体力は増やさない） |

いつでも変更でき、変更によるペナルティはない（名誉報酬の判定だけに使う）。個別調整（受けるダメージ、予兆の長さ、自動回避の補助）も用意する。

## 2. 成長（4領域）

**経験値ではなく「理解」で成長する。** 生物を観察し、痕跡を読み、遺跡を解き、人を助けると「気づき」が得られ、気づきを使って4つの領域の技能を開く。

| 領域 | 技能の例（遊び方が変わるもの） |
|---|---|
| **戦闘** | 重撃の溜めで姿勢を崩しやすくなる／回避の直後に反撃できる／銛綱で大型生物を引き寄せる |
| **探索** | **振動感知**：しゃがんで地面に手を当てると、地中の空洞の方向が分かる／登攀のスタミナが減りにくい／**滑空の旋回が鋭くなる**／**潜水で水の流れに乗れる** |
| **生態理解** | **風読み**：風向きが一目で分かり、匂いで気づかれにくくなる／**群れの警戒を解く**（群れの中を通れる）／鳴き真似で群れを誘導する／足跡から経過時間が正確に分かる |
| **工作** | **固定具**：岩壁に杭を打って登攀路を作る（次回以降も残る）／**罠の反応条件を変更**（重さ、匂い、音で作動するよう変える）／料理の効果の延長 |

- **振り直し**：拠点の「記憶の輪」で、いつでも無料で振り直せる。
- **装備構成の保存**：武器・防具・道具・技能の組み合わせを5つまで保存し、野営地（小拠点を含む）で切り替えられる。

## 3. 装備

- 武器は6系統（重撃、軽撃、射撃、罠、共闘用の道具、調査道具）で、それぞれに3〜5種類。数値の上位互換ではなく、**特性の違い**で差をつける（例：骨鎚＝姿勢崩し重視、大斧＝部位破壊重視）。
- 防具は「環境への適応」が中心になる（寒冷、耐熱、潜水、滑空、静音）。
- 素材の要求は控えめにする：1つの装備に必要な素材は3〜4種類で、主要な素材は地域の探索中に自然に集まる量とする。**低確率ドロップは使わない**（希少素材は「特定の行動を観察したときに必ず手に入る」形にする）。
- 装備の耐久値（壊れる仕組み）は導入しない。

## 4. 生物との絆

| 原則 | 内容 |
|---|---|
| 餌の連打で育てない | 絆は、その種に合った**共同活動**で深まる |
| 共同活動の例 | カゼアシ：肉食獣から守りながら水場まで同行する。ツノナガ：茂みを一緒に切り開く。ハヤイルカ：潮流に乗って一緒に泳ぐ。トサカバネ：落ちた卵を巣に戻す |
| 個体差 | 各個体に性格（勇敢／慎重／好奇心）と、得意な能力の傾向がある。**育成で調整できる**（共同活動の内容によって伸びる能力が変わる）。極端に低確率な個体を厳選する必要はない |
| 役割の分担 | 騎乗、索敵、荷運び、潜水支援などは種によって分かれており、1体ですべてをこなすことはできない（`03` 3.1） |

## 5. 生態系シミュレーション

### 5.1 階層化されたシミュレーション（距離と重要度で粒度を変える）

| 層 | 範囲 | 処理 |
|---|---|---|
| L0 **詳細** | プレイヤーの周囲 約150m | 個体ごとのAI、アニメーション、感覚、物理 |
| L1 **簡易** | 150〜600m | 個体ごとの位置と状態のみ（アニメーションは簡略化、感覚の判定は間引く） |
| L2 **群れ単位** | 600m〜地域全体 | 群れを1つの点として扱い、移動路・空腹・時刻から位置を更新する |
| L3 **統計** | 他の地域 | 個体数と分布の統計だけを持ち、訪れたときに状態を生成する |

**観測したときの整合性**：L2 から L0 に切り替わるとき、群れの中の個体は「その場で何をしていたか」（採食中、移動中、休息中）が、それまでの状態と矛盾しないように配置する。捕食イベントが L2 で起きた場合は、L0 に入ったときに死骸と痕跡が残っている。

### 5.2 個体のAI（状態機械）

```
 休息 ⇄ 採食・徘徊 ⇄ 移動（群れの移動路）
   │         │ ↘
   │         │   水を飲む（水場へ）
   ▼         ▼
  気づき → 警戒 → 逃走 ／ 威嚇 → 攻撃
                     ↘ 幼体を守る
 （肉食）空腹 → 狩り（追跡→襲撃）→ 食事 → 満腹・休息
 （腐肉食）死骸の匂い → 集まる → 食事
```

- **感覚**：視覚（視野角・距離・遮蔽）、聴覚（音の大きさ・距離）、嗅覚（風向き・距離）の3つ。
- **関係表**：種ごとに、捕食者・獲物・競争相手・共生相手を定義する。
- **群れ**：リーダー（最年長）への追従、個体間の間隔、幼体を群れの内側に置く。
- **プレイヤーへの反応**：種ごとに「無関心」「警戒して離れる」「縄張りを守る」「好奇心」などを設定する。**すべての生物がプレイヤーを見て襲ってくる設計にしない。**

### 5.3 自然に発生する生態イベント

| イベント | 発生条件 | プレイヤーの体験 |
|---|---|---|
| 狩り | 肉食獣が空腹で、獲物が群れから離れている | 遠くから見守る、横取りを狙う、獲物を助けるなど、関わり方を選べる |
| 死骸に集まる生物 | 死骸ができてから時間が経つ | 腐肉食の生物が順番に集まる（ホネツツキ → ツチネズミ → 糞虫）。図鑑の観察項目 |
| 縄張り争い | 肉食獣の縄張りが重なる | 威嚇の応酬。負けた側は去る（死ぬまで戦わない） |
| 幼体を守る群れ | 肉食獣が幼体に近づく | 成体が幼体を囲む円陣を作る |
| 植生の変化 | 草食獣の群れが長く滞在する | 草が短くなり、足跡が増え、土が見える（ゲーム内の数日で回復する） |

### 5.4 絶滅を起こさない

- 各種の個体数は、地域の「命紋の湧き」（湧き床）によって、プレイヤーの見ていない場所で補充される（世界設定と一致させる）。
- 物語上重要な個体（環守、絆を結んだ個体）は、死亡しても物語の中で扱いを決める（環守は決着の一つとして扱い、絆の個体は拠点で療養する）。
- **図鑑はどの状態でもコンプリート可能**にする（討伐した環守は、章再訪または「古代の記憶」で観察項目を埋められる）。

## 6. 痕跡と調査

### 6.1 痕跡の種類

| 痕跡 | 読めること | 表現 |
|---|---|---|
| 足跡 | 種、体重（深さ）、速度（間隔）、経過時間（崩れ・乾き） | 地面に沈んだ跡。時間とともに薄くなる |
| 折れた枝、倒れた草 | 通った方向と高さ（体の大きさ） | 草が押し倒された帯 |
| 食べ残し | 何を食べたか、食べ方（引きちぎる／噛み砕く） | 木の皮の剥がれ、骨 |
| 羽毛・鱗・毛 | 種、換羽の時期 | 地面に落ちた小物（拾える） |
| 糞 | 食性、経過時間 | ― |
| 鳴き声 | 方向、距離、状態（警戒の声、呼び合う声） | 立体音響。字幕で「種名（分かっていれば）・方向」を表示 |
| 地面の振動 | 大型生物の接近、地下の空洞 | カメラのわずかな揺れ（設定で調整可）、コントローラーの振動 |
| 水面の変化 | 水中の生物、水を飲んだ跡 | 波紋、濁り |

### 6.2 調査の流れ

1. 痕跡に近づくと、**画面は切り替えずに**、痕跡の輪郭がわずかに強調される（設定で強調の強さを調整できる）。
2. 「調べる」で、手帳にスケッチが描かれ、読み取れる事実が短く表示される（例：「深さ18cm。四本脚。重い。半日前。北へ」）。
3. 同じ一連の痕跡を複数調べると、**推理**が組み上がる（例：「足跡の間隔が急に広がる」＋「倒れた草」→「ここで何かから逃げ出した」）。
4. 推理が完成すると、次の行き先の候補（方向と地形の特徴）が手帳に記される。**地図上の目的地マーカーは原則として出さない**（手帳から「方向だけ示す」を選ぶことはできる）。

### 6.3 耳を澄ます（補助能力）

- 長押しの間、周囲の音が強調され、音源の方向が画面端に控えめに表示される。画面の色は変えない。
- 常時使う必要はない。通常の画面と音だけで判断できることを基本にする。

### 6.4 段階的なヒント（重要な謎）

重要な謎には、それぞれ3つ以上の手がかりを置く。調査手帳では、プレイヤーが望んだときだけ、段階的にヒントを表示する。
1. **気づき**：何に注目すればよいか（例：「壁画の星の数を数えよう」）
2. **方向**：どこを調べればよいか
3. **答えに近い説明**：何をすればよいか

## 7. 拠点

### 7.1 成長の流れ

| 段階 | 状態 | 発展の条件（素材だけにしない） |
|---|---|---|
| 1 野営地 | 天幕3つ、焚き火、荷車 | 開始時 |
| 2 調査隊の宿営 | 工房、研究机、交易の荷車 | 工匠イヴァを勧誘する（草海のサイドストーリー） |
| 3 小さな集落 | 研究所、交易所、保護施設、住居 | 地域の問題を2つ解決し、移住を希望する人が来る |
| 4 渡り読みの里 | 博物館、庭園、展望台、孵化施設 | 各勢力から1人ずつ人材を勧誘する |
| 5 （クリア後）環の里 | 結末に応じた姿 | 結末 |

- **建築場所の選択**：施設ごとに、置ける場所の候補が複数ある。場所によって効果が変わる（例：庭園を川辺に置くと水生植物が育ち、丘に置くと乾燥に強い植物が育つ）。
- **展示**：化石、写真、標本、壁画の復元、研究の成果が、博物館に実際の3Dの物として展示される。展示を見た拠点のNPCの会話が変わる（リセは化石の前で質問をしてくる）。
- **帰る楽しみ**：遠征から戻ると、留守中の出来事（孵化した卵、完成した研究、新しく来た住人）が見られる。

## 8. UI

| 画面 | 内容 |
|---|---|
| 通常の探索 | **最小限の表示**：画面上部に方位と風向き（細い線）。体力とスタミナは、変化したときだけ表示される。操作の説明は、近づいたときだけ |
| 調査手帳 | 目的（段階的なヒント付き）、推理、スケッチ、姉の記録 |
| 生態図鑑 | 観察の段階（遭遇 → 観察 → 痕跡 → 行動の理解）、化石の知見と創作の区別、写真 |
| 地図 | 自分で描いていく地図（歩いた場所、見た場所が描かれる）。自分で置ける印 |
| クエストの追跡 | 手帳から1つを選んで追跡する。追跡中の目的は画面の隅に短く表示 |
| 装備の比較 | 特性の違いを文章と図で表示する（数値だけにしない） |
| 収集の状況 | 地域ごと、種類ごとの達成状況 |

## 9. 快適性

| 項目 | 仕様 |
|---|---|
| セーブ | オートセーブ（区切りの行動ごと、最低5分ごと）、手動セーブ、手動3枠以上＋オートセーブ2枠を交互に使う |
| 死亡後の再開 | 直前のチェックポイント、または最後に休んだ野営地から再開する。失うものはない |
| クエストの中断 | いつでも中断でき、再開したときは中断した段階から続く |
| 取り逃しの防止 | 永久に取り逃す収集物は作らない。時期限定のものは章再訪で取得できる |
| 天候・季節 | ゲーム内の天気予報（拠点の観測所）と休息で狙える |
| 生存要素 | 空腹・渇きは導入しない。料理は「一定時間の効果」として扱う。寒さ・熱さは装備と料理で対策する「環境の読み」として扱う |

## 10. アクセシビリティ

文字サイズ（3段階以上）、字幕（話者名、音の方向）、色の識別補助（形とアイコンで区別する）、操作の割り当て変更、長押しと切り替えの選択、カメラの揺れの強さ、モーションブラーの強さ、画面の明るさ、振動の強さ。
