# 09 コンテンツ量とプレイ時間の検証計画

**この文書の数字はすべて設計目標であり、達成値ではない。** プレイ時間は、制作後のプレイテストで実測して初めて判断する。企画の見積もりだけで「達成した」とは扱わない。

## 1. 目標と配分

| 区分 | 目標時間 | 主な中身 |
|---|---|---|
| 本編（初回クリア） | 75〜90h | 5幕、中ボス4体、ラスボス、移動と必須の調査 |
| 地域サイドストーリー | 45〜60h | 24系統（1系統 約2〜2.5h） |
| 生態研究と図鑑完成 | 30〜40h | 98種の研究（種によって作業が違う） |
| 遺跡・洞窟・秘境探索 | 30〜45h | 大型遺跡12（1か所 1.5〜2.5h）、小規模地点48（1か所 10〜25分） |
| 育成・装備構築・攻略課題 | 25〜35h | 技能、装備、強敵18体、熟練者の試練 |
| クリア後の物語と遠征 | 40〜60h | 大遠征12本、生態復興、古代の記憶、最終仮説 |
| **全コンプリート** | **245〜330h** | 上の合計 |
| 主要サイド＋探索込み | 150〜200h | 本編＋サイド＋遺跡探索の一部 |

1日3時間なら、全コンプリートまで約82〜110日。

## 2. 二重計上をしない決まり

同じ時間を2つの区分に数えない。計測のときは、1秒ごとに「そのとき何のために動いていたか」を一つだけ割り当てる。

1. **追跡中の目的**（手帳で選んでいる目的）がある間の時間は、その目的の区分に数える。
2. 目的を追跡していない移動・探索の時間は、次に達成した物（発見・観察・遺跡）の区分に数える。
3. 移動中に偶然起きた生態イベントを観察した時間は「生態研究」に数え、移動していた目的の区分からは引く。
4. 拠点での時間（会話・建設・展示を見る）は「育成・拠点」に数える。
5. 死亡からの再開・読み込み・メニューの時間は別に記録し、どの区分にも数えない（ただし合計には「遊んだ時間」として報告する）。

## 3. 時間を水増ししない決まり

次の方法でプレイ時間を延ばさない。見つけた場合は設計の不具合として直す。

| 禁止事項 | 検出の方法（計測項目） |
|---|---|
| 現実の日付による解放、ログインの義務 | 仕組みとして作らない（コード審査） |
| 長時間の放置 | 「操作なしで進む時間」が合計の2%を超えたら警告 |
| 過剰な素材の要求 | 1つの装備・施設に必要な素材の収集時間が15分を超えたら見直す |
| 低確率のドロップ | 仕組みとして作らない（確定入手のみ） |
| 同じ敵の無目的な大量討伐 | 同じ種を30分で10回以上倒している人が10%を超えたら、その報酬の設計を見直す |
| 移動の水増し | 「発見の間隔」（次の新しい物までの時間）の中央値が90秒を超える区間を探し、配置を見直す |

## 4. 計測する値（テレメトリー）

プレイテスト用の版にだけ組み込む（製品版では、利用者の同意なしに送らない）。

| 値 | 意味 |
|---|---|
| 区分ごとの時間 | 上の決まりで割り当てた時間 |
| 発見の間隔 | 新しい景観・痕跡・生物・遺跡に出会うまでの時間 |
| 判断の回数 | 選択肢のある場面（接近の方法、決着の方法、建設場所など）の数 |
| 迷い時間 | 目的があるのに、進展のない時間。ヒントを開くまでの時間 |
| ヒントの使用 | どの謎で、どの段階のヒントを開いたか |
| 死亡の場所と原因 | 難度の偏り |
| 移動手段の割合 | 徒歩・騎乗・滑空・船・潜水の比 |
| 生態イベントの目撃数 | 1時間あたり（目標 2〜4回） |

## 5. 検証の段階

| 段階 | 対象 | 人数（目安） | 判断すること |
|---|---|---|---|
| 1 垂直スライス | 草海〜樹海の入口、オルガ | 5〜8人 | 30〜60分に収まるか。探索したくなるか、生物を観察したくなるか、戦闘が読めるか、次を遊びたくなるか |
| 2 第1〜2幕 | 草海・樹海・内海・峡谷 | 10〜15人 | 1地域あたりの時間。攻略順の自由度で物語が崩れないか |
| 3 本編通し | 全地域 | 15〜20人 | 本編 75〜90h に収まるか（遊ぶ速さの違いで分布を見る） |
| 4 全体 | クリア後を含む | 長期テスト 5〜10人（2か月以上） | 245〜330h の現実の分布。2か月遊んだ後に、旅した場所と出会った生命を具体的に思い出せるか（面談） |

**判断の基準**：中央値が目標の範囲に入り、上下の25%の人の値が範囲の±30%以内であること。範囲に入らない場合は、中身を足すか削るかを判断する。**時間を延ばすために同じ種類の作業を足さない。**

## 7. 要素の審査（新しい要素を加えるたびに）

1. プレイヤーは何を見て心を動かされるか。
2. 何を理解し、どんな判断をするか。
3. 成長すると、以前と何が変わるか。
4. その体験は、この世界である必要があるか。

4つのうち2つ以上に答えられない要素は採用しない。
