# 01 世界観設定

## 1. 世界の仕組み ― 「原環（げんかん）」

### 1.1 概要（作品独自の架空設定）

| 用語 | 定義 |
|---|---|
| **命紋（めいもん）** | 生物が死ぬと体組織に残る「形と振る舞いの記憶」。死骸が分解される過程で土・水・風に溶け、最終的にアーケアへ運ばれる。 |
| **記憶層（きおくそう）** | アーケアの体内にある層状の組織。命紋を年輪のように積み重ねて保存する。 |
| **大巡り（おおめぐり）** | 数百年ごとにアーケアが記憶層から命紋を「読み出し」、大地の湧き床から生命を再び芽吹かせる現象。**過去のどの時代の命紋も読み出されるため、異なる時代の生物が同じ大地に共存する。** |
| **湧き床（わきどこ）** | 温泉や泥火山に似た再生の場。発光する微生物膜に覆われる。幼体や卵は湧き床の周辺で見つかる。 |
| **四巡り（よめぐり）** | 循環を担う4つの流れ。**地巡り**（森と草地の更新）、**潮巡り**（死を海の底へ還す）、**風巡り**（種と微生物を運ぶ）、**時巡り**（季節の道筋を伝える）。 |
| **環守（わもり）** | 四巡りの要となる巨大個体。オルガ（地）、ネレム（潮）、セイラ（風）、ウルマ（時）。単なる強い個体ではなく、行動そのものが循環の一部になっている。 |
| **写し環（うつしわ）** | 環刻文明がアーケアの器官を模倣して作った装置群。共振柱（生物の誘導）、水門（潮と回遊の制御）、嵐の塔（気候）、熱炉（地熱）、保存庫（命紋の貯蔵）など。 |

### 1.2 実在の知見と創作の区別（図鑑・会話での表記規則）

図鑑の各項目には、次の2つの欄を必ず分けて書く。

- **【化石からわかること】** 実在の古生物学に基づく知見。骨格の形、推定される体の大きさ、生息した時代、食性の推定など。確実でない推定には「〜と考えられている」と書く。
- **【ヴァルナでの姿】** 作品独自の創作。命紋から再生された結果としての生態・能力・色彩・行動。

例：
> **ソラクビ**（竜脚類がモチーフ）
> 【化石からわかること】長い首と尾をもつ巨大な植物食恐竜のなかま。骨の内部に空洞（含気骨）があり、体の大きさのわりに骨格が軽かったと考えられている。
> 【ヴァルナでの姿】群れで草海を渡り、首を振って霧を割る。歩いた跡が水の通り道になり、草海の小川の多くはソラクビの古い道である。

**用語の規則**：作中の人物は「恐竜」「翼竜」などの現実の分類名を使わない。人物は作中の語（「長首」「翼持ち」など）を使い、図鑑の【化石からわかること】欄でのみ現実の分類名を使う。こうして、作中の世界と現実の知識が混ざらないようにする。

## 2. 歴史の5段階

| 段階 | 名称 | 時期（作中暦） | 何が起きたか |
|---|---|---|---|
| Ⅰ | **大形成期**（おおかたちのとき） | 人間以前 | 巨大生物が大地を形づくった時代。アーケアが内海を抱くように丸まり、環状山脈になった。巨獣の踏み跡が谷になり、倒木が湿地を作った。 |
| Ⅱ | **渡り暮らしの時代** | 約6000〜3000年前 | 人間が生物の移動と季節に合わせて暮らした時代。「巡りの歌」で移動路を伝えた。渡りの民の祖先。 |
| Ⅲ | **環刻文明期** | 約3000〜1200年前 | アーケアの器官を模倣した写し環で、食料・気候・寿命を管理した。人口が爆発的に増え、大都市が生まれた。 |
| Ⅳ | **凍刻（とうこく）** | 約1200〜1000年前 | 生物の移動路と季節を固定した。死がアーケアへ還らなくなり、記憶層が痩せ、大巡りが止まった。気候が崩れ、生物が再生されなくなり、文明は崩壊した。 |
| Ⅴ | **現代・再巡（さいじゅん）の兆し** | 現在 | 人々は遺跡の上に暮らしている。止まっていた装置の一部が自然に、あるいは復元局によって再び動き出し、季節外れの大移動などの大異変が始まった。 |

### 2.1 各時代の痕跡（どこで・何によって分かるか）

| 痕跡の種類 | Ⅰ 大形成期 | Ⅱ 渡り暮らし | Ⅲ 環刻文明 | Ⅳ 凍刻 | Ⅴ 現代 |
|---|---|---|---|---|---|
| **地層**（赤層の峡谷で最もよく読める） | 巨大な足跡の化石が残る赤色層。川の流路が曲がりくねる | 焚き火の炭層、骨器が混じる | 規則正しい水路と「環銅」の緑青を含む層 | **灰白層**：化石がほとんど出ない薄く白い層。世界中で同じ厚さ | 灰白層の上に新しい土。再生した生物の骨 |
| **建築** | ― | 石積みの風よけ、巨獣の肋骨を使った住居 | 同心円の都市、環状の水門、共振柱 | 途中で止まった工事跡、封鎖された扉 | 遺跡を再利用した集落、灯台（元は気候塔） |
| **化石** | 現代の同種より巨大な祖型の化石 | 人と生物が並んで歩いた足跡 | 装置を体に埋め込まれた生物の化石 | 同じ向きで倒れた群れの大量化石（移動路の固定による大量死） | 化石と一致する現生の生物 |
| **生物の行動** | 環守の古い習性（オルガの倒木など） | 人の歌に反応して進路を変える群れがいる | 装置の共振音に反応する個体がいる | 固定路の名残で、意味のない場所を巡回する群れがいる | 季節外れの大移動 |
| **言語** | ― | 「巡りの歌」の古い語彙 | 環刻語：輪形の文字。「ヴァル＝環」「ナ＝大地」「アー＝母」「ケア＝眠り／殻」 | 命令形の銘文が急に増える（「止まれ」「留まれ」） | 地名に古語が残る。**ヴァルナ＝「環の大地」** |
| **道具** | ― | 骨の足跡定規、風読みの羽根 | 環銅の制御鍵、命紋の記録盤 | 壊された制御鍵、鎖 | 復元局が作った制御鍵の複製品 |
| **伝承** | 「山は眠る母」 | 「死は海へ、種は風へ、道は祖母へ」（四巡りを表す） | 「環の民は冬を殺した」 | 「動かぬ春」の昔話 | 「大巡りが来れば、世界は一度さらわれる」 |

**原則**：真相を知る手段は1つにしない。地層・言語・伝承・生物の行動のどれからでも、同じ事実に近づけるように置く。

## 3. 地理概要

内海「潮鏡の内海」を、アーケアの背殻＝環状山脈が北〜東〜南にかけて弧を描いて囲む。西は草海へ開けている。**プレイヤーはゲームの最初から、地平線上に続く「妙に規則的な節をもつ山並み」を見続ける。**

```
            ⑥白嶺の氷原
        ⑤天帆の断崖   ═══環状山脈（背殻）═══
   ②翡翠の樹海                          ⑦黒曜の火口帯
 ①暁の草海      ④ 潮 鏡 の 内 海       ║
   ③赤層の峡谷                          ║
            ⑧星骸の盆地 ── 原環の心臓（内海の底〜山脈の内部）
```

## 6. 勢力

| 勢力 | 守りたいもの | 問題点 | 歩くと分かること（現地での体験） |
|---|---|---|---|
| **渡りの民** | 生物の移動とともに生きる自由と、巡りの歌 | 定住民を排除し、技術を拒む。家畜にした《カゼアシ》の群れが草地を食べ尽くす地域がある | 草海の移動集落を訪ねると、子どもが足跡遊びで字を覚えている。一方で、放牧地の周囲だけ草が根まで食べられ、土が露出している |
| **灯台同盟** | 沿岸の集落、交易、船乗りの命 | 乱獲、遺物の密売、生物を排除するための銛網 | 灯台の中に入ると、それが元は環刻文明の気候塔だったと分かる。網に絡まった《オオコウラ》の幼体を見つけられる |
| **石環院** | 知識と遺跡 | 知識の独占、都合の悪い真実の封印、害をなす装置の保存 | 院の書庫では、閲覧できる棚と閉ざされた棚がはっきり分かれている。院の研究者の多くは誠実で、封印を知らない |
| **復元局** | 都市ルメナの8万人の暮らし | 副作用を理解しないまま装置を再稼働する。熱炉の熱を都市へ転用した | ルメナの街は常春で、花が咲き乱れて美しい。しかし外周には、石肺を患う人々の療養区が広がっている |

**設計原則**：どの勢力にも、プレイヤーが好きになれる人物と、嫌いになれる判断を必ず置く。勢力ごとの評判値は持たせず、**地域の問題を解決した結果**として関係が変わる（例：灯台同盟の漁村で銛網を外した結果、翌シーズンに漁獲が回復し、漁師が態度を変える）。
