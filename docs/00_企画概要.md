## 1. 一言で

**古代生物を「倒すべき敵」ではなく「読むべき世界」として描くオープンワールド。**
足跡・鳴き声・風向き・地層を読む若き「渡り読み」が、姉の残した観測記録を追ってヴァルナを旅する。やがて、生命と環境の「記憶」を蓄えて再生する仕組みが見えてくる。遠くに見えていた環状の山脈は、その仕組みそのものだった。

## 2. プレイヤーに届ける体験（5本柱）

| # | 柱 | プレイヤーが実際にすること | 失敗例（避けるもの） |
|---|---|---|---|
| P1 | **景色の奥へ、自分の意思で進みたくなる探索** | 遠くの巨木、不自然な岩の並び、渡りの方向、星と壁画の一致を見て、自分で行き先を決める | 画面に常時出るマーカーをなぞるだけ |
| P2 | **生物の行動を理解するほど有利になる冒険** | 風下から近づく、群れの移動を予測して先回りする、捕食者の狩りの後を追って死骸から情報を得る | 全生物が視認即敵対。図鑑は倒した数で埋まる |
| P3 | **巨大生物の重量と知性を感じる戦闘** | 突進を巨木へ誘う、泥地で脚を奪う、呼吸の間隔から浮上点を読む、群れとの距離を測る | 体力の多い的を脚元で延々と殴る |
| P4 | **世界の成り立ちを自分で解き明かす物語** | 地層の灰白層、装置を埋め込まれた化石、古語「ヴァル＝環」「ナ＝大地」から真相に近づく | 長文の記録を読ませて説明する |
| P5 | **成長した能力と知識で、同じ場所を別の方法で攻略する喜び** | 振動感知で見つけた空洞、固定具で作る壁の道、群れの警戒を解いて通る峡谷 | 数値だけ上がって同じ遊び方が続く |

**5本柱の結合（中心の流れ）**
> 美しい景観の中で古代生物を理解する → その知識で道が開く → 人々との関係が変わる → 最後に世界の未来を選ぶ。

どの要素も、この流れのどこかを担う。担わない要素は削る（`docs/09` の「要素審査」を参照）。

## 3. コアループ

```
 ┌─────────── 見る（景観・痕跡・音）───────────┐
 │                                              ▼
報酬・変化 ◀── 解決（戦闘/誘導/修復/交渉） ◀── 読む（調査手帳・図鑑・地層）
 │   ▲                                          │
 │   └─────── 判断（ルート・接近法・準備） ◀──┘
 ▼
拠点が育つ／地域が変わる → 新しい景観と手がかりが見える → 最初に戻る
```

- **ミクロ（数分）**：痕跡を見つける → 何が起きたか推測する → 接近法を選ぶ → 観察・採集・戦闘。
- **ミドル（1〜3時間）**：地域の異変を調査 → 遺跡・人・生物の3方向から手がかり → 決着 → 地形と生態が変わる。
- **マクロ（数十時間）**：4つの循環（地・潮・風・時）を取り戻す → 世界の仕組みを理解する → 結末の条件を自分の旅で揃える。

## 4. 作品の核心（ネタバレ要約・開発内部用）

- ヴァルナの内海を囲む**環状山脈は、休眠する超巨大生物《原環母獣アーケア》の背殻**である。
- アーケアは死んだ生命の「命紋（めいもん）」を体内の**記憶層**に蓄え、数百年ごとの「大巡り」で**湧き床**から再び芽吹かせる。**異なる時代の生物が共存するのは、過去の命紋から再生された生命が同じ大地で暮らしているため**（作品独自の架空設定）。
- 4体の**環守（わもり）**が循環を担う：オルガ＝地巡り（森を倒し草地を作る）、ネレム＝潮巡り（死骸を海溝へ運ぶ）、セイラ＝風巡り（種子と微生物を運ぶ）、ウルマ＝時巡り（季節の道筋を群れに伝える）。
- 古代の**環刻（かんこく）文明**はアーケアの器官を模倣した「写し環」装置で食料・気候・寿命を管理した。生物の移動と季節まで**固定**した結果、アーケアへ死が還らなくなり、循環が止まって文明は崩壊した（「凍刻（とうこく）」）。
- 現代：復元局が白嶺の熱炉の熱を都市ルメナへ引いたため、ウルマの群れが季節外れに南下し、押し出された草海の巨大草食獣が主人公の故郷を襲った。**この経路を開く鍵を復元局に渡したのは、姉イスカ自身だった。**

## 5. 序盤30分の絶景（3つ以上）

プレイヤーが**自分で歩いて**到達する。カットシーンは導入の短いものだけ。

| # | 時刻の目安 | 場所 | 見えるもの | 遊びとの結合 |
|---|---|---|---|---|
| V1 | 0〜5分 | 渡りの丘（故郷の跡） | 朝霧の草海を横切る《ソラクビ》の群れ。遠景に環状山脈の稜線 | 群れの進行方向が最初の目標を示す（UIマーカーなし） |
| V2 | 10〜15分 | 大河の曲がり（野営地の上） | 翼竜《カゲワタリ》の影が草原を横切り、川で狩りをする。夕方には川面が金色に反射する | 影を追うと川辺の痕跡と側クエストへつながる |
| V3 | 20〜30分 | 翡翠の門（樹海の入口） | 霧を通る光の柱と巨木の根。見上げるほど暗くなる樹冠 | 光と音を頼りに進む、樹海の探索文法の導入 |
| V4 | 任意（夜） | 草海の夜 | 星空の下に浮かぶ生物発光の虫と、眠る群れの寝息 | 夜にしか見られない行動が図鑑に記録される |

## 6. 何が他と違うか

1. **生態の「読み」が主要な操作**：特殊視覚に頼らず、通常画面の痕跡（沈んだ足跡、倒れた草、食べ残し、羽毛）と音で状況が分かる。
2. **ボスは「その地域の生態系の要」**：倒すか救うかではなく「危機をどう解決するか」を問う。決着の方法によって世界に残る痕跡が変わり、報酬の価値は揃える。
3. **最大のランドマーク＝ラスボス**：最初の数分から見えている山脈が、終盤で別の意味を持つ。
4. **結末は旅の実績から組み立てる**：最後の会話の選択肢だけで決まらない。各地で実証した共存方法、救った集落、理解した生態が選択肢と代償を形づくる。
