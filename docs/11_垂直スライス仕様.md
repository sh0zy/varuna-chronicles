# 11 垂直スライスの実装範囲と完成判定

## 1. 目的

30〜60分で、この作品の中心の流れ――**景観の中で古代生物を理解し、その知識で道が開き、人々との関係が変わる**――が面白さとして成立するかを確かめる。見た目は仮素材で、見た目の完成品質はこの区間の判定の対象外とする（製品版の垂直スライスで判定する）。

## 2. 区域

草海の西端（渡りの丘）から、大河を越えて、草海と樹海の境（倒木地帯）、根の谷を越えた翡翠の門・根の地下道の入口まで。約1.6km四方。

```
        北
   九本石          根の地下道（区域の終わり）
      ・               ・翡翠の門
  古い群れの道    ═══根の谷═══（オルガの倒木の橋）
      ・     大河      ・見張り塔
   渡りの丘  ／ 野営地   翡翠の縁・ 倒木地帯
      ・   ／  砂州・      泥地・  ・オルガの広場
    柵・棘の茂み  浅瀬の渡し    ソテツの茂み
```

## 3. 含めるもの（依頼の項目との対応）

| 依頼の項目 | 実装した内容 |
|---|---|
| 草海から樹海へつながる探索区域 | 連続した地形（丘・大河・崖・泥地・根の谷・樹海）。壁ではなく、川の深さ・谷・山で境界を作る |
| 作品を代表する絶景 | V1 渡りの丘（霧の群れと環状山脈）、V2 大河の曲がり、V3 翡翠の縁（光の柱）、V4 草海の夜 |
| 草食・肉食・小型生物の生態行動 | 10種の骨格つき生物＋簡易の3種。群れの移動、採食、水飲み、睡眠、狩り、死骸と腐肉食、縄張り争い（オオアギトがクサガリから獲物を奪う）、幼体を守る、ヒメヨロイが棘の低木を食べる、翼竜が川辺に降りて狩る |
| 徒歩・基本戦闘・痕跡調査・騎乗 | 歩く・走る・しゃがむ・泳ぐ・回避・軽攻撃・重攻撃（溜め）・投石・注目・道具（音玉・煙玉）・足跡の調査（種・深さ・経過時間・速さ・向き）・耳を澄ます・騎乗（コハク） |
| 短いサイドクエスト | 「柵の向こうの道」（調査で認識が変わる。2つの結末）、「はぐれたコハク」（騎乗の共同活動） |
| 小規模な遺跡 | 共振の見張り塔（壁画と輪石の謎。解くとオルガの戦いが楽になる） |
| 拠点と図鑑の基本機能 | 野営地（会話5人・休息と天気予報・補充・展示棚・写真の板・見張り台の建設場所の選択）、図鑑13種（化石の知見と創作の区別、観察項目） |
| 翠角王オルガの調査・戦闘・解決後の地域変化 | 調査（足跡・倒木・唸り・幼体）→3段階の戦い（巨木・泥地・幼体を守る）→装置の引き抜き→オルガが古い移動路を通って根の谷の巨木を倒し、橋が架かる。群れの移動路が東へ延びる |
| セーブと再開 | 手動3枠＋自動2枠（交互）、検証つきの読み込み、戦闘中の段階からの再開 |
| グラフィック・音・UIの品質見本 | 大気と霧、草、植生、水、昼夜と天候、手続き合成の音、方位と風向き、音の字幕、フォトモード |

## 4. 含めないもの（明示）

- 他の7地域、中ボスの残り3体、ラスボス、結末、クリア後。
- オルガの「鎮静」「討伐」による決着（設計のみ。今回は「装置からの解放」だけを実装）。
- 登攀・滑空・船・潜水、装備の作成と比較、料理、化石の復元、壁画の復元。
- 製品品質のモデル・アニメーション・音。

### 5.3 性能の判定

`08` の 4.2 を参照。この開発機（内蔵GPU・バッテリー駆動）では、中画質の 1600×900 で 20〜25ms。低画質の目標（30fps）は多くの場面で満たすが、読み込み直後の引っかかりが残る。**電源接続時と単体GPUでの測定は未実施。**

## 6. 遊び方

```
npm install
npm run dev
```

ブラウザ（Edge・Chrome の最新版）で `http://127.0.0.1:5173/` を開く。画面をクリックすると、マウスで視点を動かせる。操作は `05` の 1.1、またはゲーム内の「操作」タブ。
