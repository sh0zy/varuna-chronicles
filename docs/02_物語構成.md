## 2. 各幕の具体的な出来事

### 第1幕 故郷の異変と旅立ち

1. **渡りの丘（開始）**：トワは姉イスカに頼まれ、群れの帰還を観測するため一人で丘にいる。朝霧の中を《ソラクビ》の群れが横切る（V1）。季節は「芽吹きの月」で、本来なら群れはまだ北にいるはずだ。**足跡が深すぎる。何かから逃げている。**
2. **大移動**：地響きとともに、別の群れが次々と南下してくる。トワは足跡と風から群れの進路を読み、集落「ハセの輪」へ走る。プレイヤーは、群れの隙間を読み取って進む短い追跡劇を操作する。**失敗しても最後のチェックポイントから数秒でやり直せる。**
3. **故郷の喪失**：集落の半分が踏み荒らされる。姉は前夜から「北の震え」を調べに出ていて、戻らない。姉の天幕には観測記録（調査手帳の原型）が残されている。
4. **野営地へ**：生き残った人々と一緒に、大河の曲がりにある調査隊の野営地（拠点）へ移る。エナ婆に再会する（V2はこの移動中に見える）。
5. **姉の最初の記録**：「樹海の境で、翠角王が泣いている」。野営地の周囲で痕跡調査、戦闘、騎乗の基本を学ぶ（これらが垂直スライスの範囲になる）。
6. **オルガの前兆**：巨木が倒れる音、ねじ曲げられた回遊路、群れからはぐれた幼体。トワは翡翠の門（V3）へ向かう。
7. **第1幕の終わり**：姉の記録の続きを読むと、4つの地名と「四つの巡りが同じ根を持つ」という走り書きが見つかる。ここから第2幕が始まり、世界が開く。

> 設計上の注意：第1幕ではオルガとの本格的な対決は行わない。オルガは第2幕の4体のひとつで、第1幕では「最も近くにいる環守」として前兆と調査を見せるだけにする。これにより、プレイヤーは翠角王を最初に解決してもよいし、後回しにしてもよい（垂直スライスでは検証のため、オルガの解決までを一続きで遊べるようにする）。

### 第2幕 四つの巡り（順不同）

各中ボス編は「**前兆 → 調査 → 地域の物語 → 決着 → 世界の変化**」の5段で構成する（詳細は `04_ボス設計.md`）。

| 編 | 地域 | 協力者 | 地域の物語の核心 |
|---|---|---|---|
| 翠角王オルガ | ①草海／②樹海の境界 | タルク、渡りの民 | 草地を必要とする渡りの民と、森を守りたい樹海の住人。オルガが木を倒さないと草海は森に呑まれる |
| 潮葬竜ネレム | ④内海 | ロウ、灯台同盟 | 船を襲う怪物を殺すのか。死骸が海底へ運ばれないため、内海が腐り始めている |
| 天帆翼セイラ | ⑤断崖 | 断崖の営巣守「ハヤテ衆」、セト | 人工嵐を起こす塔は、断崖の村の風車の動力でもある |
| 白嶺祖母ウルマ | ⑥氷原 | 氷原の定住民「炉守」、ディオン | 熱炉の熱が都市へ引かれ、温かな谷が凍った。**故郷を襲った大移動の直接の原因が明らかになる** |

#### 攻略順に合わせた調整 ― 「地域の事実」と「総合の理解」の二層構造

物語の情報を2種類に分ける。

- **地域の事実**：その地域でしか分からない事実。どの順番で訪れても、その地域で明らかになる。（例：「熱炉の熱が都市へ引かれた」は必ず白嶺で分かる）
- **総合の理解**：解決した環守の**数**に応じて段階的に開く理解。**どの環守を解決したかではなく、何体目か**で内容が決まる。

| 解決数 | 開く「総合の理解」 | 提示の方法 |
|---|---|---|
| 1体目 | 「装置が生き物を苦しめている」 | 装置から取り出した部品を、セトが解読する |
| 2体目 | 「2つの装置は同じ文字の命令を刻まれている。どこかで一つにつながっている」 | 2つの部品を並べると、文字の輪がつながる |
| 3体目 | 「4体は偶然の強者ではなく、それぞれ巡りの一部を担っている（環守）」 | エナ婆が「巡りの歌」の3節目を思い出したふりをする（実は隠していた） |
| 4体目 | 「4つの巡りの先に、盆地の最後の都市がある」→ 第3幕へ | 4つの部品が羅針盤になり、星骸の盆地を指す |

**会話の出し分け**：各編の会話は「解決数」と「他の編の地域の事実を知っているか」の2条件で分岐させる。例えばウルマ編でディオンが熱炉について話す台詞は、「ネレム編でロウの密売を知っている」場合、「遺物はどこから来たと思う？」という追及の選択肢が増える。

**地域の事実の依存を作らない**：ある編の解決に、別の編の地域の事実を**必須にしない**。知っていれば選択肢が増える（加点）だけにする。

### 第3幕 星骸の真実

1. **盆地への降下**：4つの部品の羅針盤に従い、断層の底へ降りる。夜になると、微生物の光が巨大な骨格の輪郭を浮かび上がらせる。
2. **姉との再会**：終環都市ユラ・メネスの入口で、イスカと再会する。生きていた。
3. **古代文明の真実**：都市の記憶庫で、凍刻の記録を見る（映像ではなく、**プレイヤーが操作して記録盤の輪を回すと、都市の模型が過去の姿へ戻っていく**演出）。文明は移動路と季節を固定し、死を還さなかったことで滅びた。
4. **姉の計画**：イスカは、4体の環守が戻った今こそ、盆地の「起動環」で大巡りを再開すべきだと言う。そうすれば、ルメナの常春を支える装置は動力を失い、都市の外周区は放棄せざるを得ない。
5. **姉の秘密**：熱炉の鍵を復元局に渡したのがイスカだったと分かる。ウルマ編を既に終えていれば、ここで主人公自身がそれに気づく（台詞が変わる）。
6. **仲間との対立**：タルク（循環の再開に賛成し、定住民を切り捨てようとする）、ディオン（再開に反対し、都市の側に立つ）、セト（石環院の封印を暴くか迷っている）、ロウ（ネレム編の決着によって立場が変わる）。主人公はどちらの側にも完全にはつけない。
7. **第3幕の終わり**：イスカが起動環を動かす。主人公はそれを止めるか、手伝うかを選べる。**どちらを選んでも大巡りは始まる**（止めようとしても、4体の環守の回復によって、アーケアの覚醒はすでに避けられない段階にある）。主人公の選択は、第4幕での姉と仲間の態度に影響する。

### 第4幕 巡りの再開と代償

1. **世界の変化**：大巡りが始まる。各地で湧き床が活性化し、これまで見られなかった生物（過去の時代の命紋）が現れる。景観が変わる（例：草海に新しい小川が生まれ、峡谷の化石層から湧き床が噴き出す）。
2. **代償の表面化**：同時に、アーケアの損傷が原因の「還り損ね」（形を保てない再生体）が現れる。ルメナの常春の装置が止まり、雪が降る。
3. **各地の被害への対応**（順不同の地域クエスト群）：第2幕で解決した地域の状態によって、被害の内容と、協力してくれる人・生物が変わる。**第2幕の決着の違いがここで「返ってくる」**。
4. **黒曜の火口帯**：復元局の秘密施設「鍛造殿」で、アーケアを強制的に眠らせる「鎮め環」が作られていることを知る。ディオンの娘の病の真因（循環の固定による土の痩せ）も明らかになる。
5. **アーケアの覚醒**：環状山脈が動く。遠景の「山」が首をもたげる。**序盤から見えていた地平線の稜線が、背殻の節だったと判明する。**アーケアは生物も人間もまとめて消し、世界を最初から再生する「全還し」を始める。
6. **最後の準備**：避難、補給、協力者の配置を行う。何を準備したかが最終戦の構成に返ってくる。

### 第5幕 原環母獣

1. **心臓への道**：内海の水が引き、海底が露出する。その先に「原環の心臓」が開く。
2. **最終戦**（詳細は `04_ボス設計.md`）：地形からの脱出 → 背殻の生態系の攻略 → 再生器官と感覚器官への対処 → 本体との直接戦闘 → 最後の選択。
3. **最後の選択**：これまでに揃えた条件によって、選べる結末が決まる。
4. **エピローグ**：選んだ結末の世界で、翌年の「芽吹きの月」を迎える。渡りの丘に再び群れが来る（冒頭の V1 と同じ構図で、世界の変化を見せる）。

## 3. 結末

### 3.1 3つの結末

| 結末 | 名称 | 内容 | 代償 |
|---|---|---|---|
| A | **灯の環**（ともしびのわ） | 鎮め環でアーケアを再び眠らせ、人間が写し環を使って循環を維持する。復元局と石環院が共同で「巡り監」を作る | 生物の移動は管理され、予測できない野生は減っていく。一部の種は再生されなくなり、保存庫の中にしか残らない。人間は永遠に装置の番をし続ける |
| B | **還りの環**（かえりのわ） | 人々は居住地を移し、アーケアによる自然な再生（内海盆地の部分的な作り直し）を受け入れる | 都市ルメナと沿岸の集落は失われる。景観が大きく変わる。避難路が準備されていないと、多くの人が故郷を失ったまま散り散りになる |
| C | **分かち環**（わかちわ） | 各地で実証した共存の方法を組み合わせ、生命と人間が循環を分担する。環守が巡りを担い、人間は装置を縮小して補助に回る | **万能の解決ではない。** ルメナは常春を失い、外周区は放棄される。アーケアとの対話役「環読み」として、イスカ（または条件によってはトワ）が心臓に残る。一部の地域では巡りが不安定なまま残る |

### 3.2 結末の条件（最後の会話だけで決めない）

結末の選択肢は、最終戦の「最後の選択」で示す。しかし、**選択肢が現れる条件と、その結末の質は旅の中で揃える**。条件は調査手帳の「最終仮説」ページで、いつでも確認できる（隠し条件にしない）。

| 結末 | 選択肢が現れる条件 | 結末の質を上げる要素 |
|---|---|---|
| A 灯の環 | 常に選べる（鎮め環は第4幕で必ず入手する） | 石環院の封印記録を公開したか、復元局の装置を理解したか（理解が足りないと維持の負担が重く描かれる） |
| B 還りの環 | 「避難路」を3地域以上で確保している（渡りの民の案内、灯台同盟の船、氷原の隠れ谷など） | 確保した避難路の数に応じて、移住後の暮らしの描写が変わる |
| C 分かち環 | 「共存の実証」を4つの巡りすべてで1つ以上、合計8つ以上集め、さらにエナ婆の歌の最後の節を聞いている | 実証の数と種類によって、どの地域が安定し、どこが不安定なまま残るかが変わる |

**共存の実証**とは、地域のサイドストーリーで人と生物の関係を実際に変えた成果である（例：柵に小さな通り道を開けて《ヒメヨロイ》が戻った草海の村）。全24系統のうち16系統以上に実証があり、中ボスの決着方法（討伐でも解放でも）にもそれぞれ実証が含まれる。**非殺傷の決着だけが結末Cにつながるのではない**（討伐した場合は、渡りの民が制御された野焼きで草地を作る、という別の実証になる）。

## 4. クリア後

- **通常のクリア後**：選んだ結末の後の世界を探索できる。景観、生物、集落の暮らしが結末に応じて変わっている。第19項の5系統（生態復興、大遠征、古代の記憶、最終仮説、熟練者の試練）はここで解放する。
- **章再訪**：クリア後、タイトル画面と拠点の「記憶の輪」から、各幕の主要な分岐点に戻れる**独立したモード**。現在の世界の状態は変えない。章再訪で見た別の結末と分岐は「年代記」に記録され、図鑑と実績の対象になる。章再訪の中で得た装備と素材は本編に持ち込まない（名誉記録だけを持ち帰る）。
